# Discord サーバー・チャンネル構成ガイド

## 推奨サーバー構成

**新しいDiscordサーバーを1つ作成**し、3体のBotを全て招待します。
チャンネルのアクセス権限で各Botの担当範囲を制御します。

## チャンネル構成

Discordサーバーに以下のチャンネルを作成してください:

```
📁 ── プロジェクト管理 ──
  #command-center    ← ユーザー + Alpha のみ。プロジェクト指示・報告
  #project-log       ← 全Bot読み取り可。進捗ログ・決定事項

📁 ── タスク指示 ──
  #beta-tasks        ← Alpha (書き込み) + Beta (読み取り・書き込み)
  #gamma-tasks       ← Alpha (書き込み) + Gamma (読み取り・書き込み)

📁 ── レビュー ──
  #review            ← Alpha (レビュー) + Beta/Gamma (成果物投稿)

📁 ── 一般 ──
  #general           ← 全員。自由なやりとり
```

## チャンネル作成手順

### 1. カテゴリとチャンネルを作成

1. Discordサーバーで **サーバー設定 → チャンネル** を開く
2. 「カテゴリを作成」で以下の3カテゴリを作成:
   - `プロジェクト管理`
   - `タスク指示`
   - `レビュー`
3. 各カテゴリ内に上記のテキストチャンネルを作成

### 2. Botの権限設定

各チャンネルの **チャンネル設定 → 権限** で以下を設定:

#### #command-center
| メンバー | メッセージ閲覧 | メッセージ送信 |
|---------|:---:|:---:|
| ユーザー | ✅ | ✅ |
| Alpha Bot | ✅ | ✅ |
| Beta Bot | ❌ | ❌ |
| Gamma Bot | ❌ | ❌ |

#### #beta-tasks
| メンバー | メッセージ閲覧 | メッセージ送信 |
|---------|:---:|:---:|
| Alpha Bot | ✅ | ✅ |
| Beta Bot | ✅ | ✅ |
| Gamma Bot | ❌ | ❌ |

#### #gamma-tasks
| メンバー | メッセージ閲覧 | メッセージ送信 |
|---------|:---:|:---:|
| Alpha Bot | ✅ | ✅ |
| Gamma Bot | ✅ | ✅ |
| Beta Bot | ❌ | ❌ |

#### #review
| メンバー | メッセージ閲覧 | メッセージ送信 |
|---------|:---:|:---:|
| Alpha Bot | ✅ | ✅ |
| Beta Bot | ✅ | ✅ |
| Gamma Bot | ✅ | ✅ |

#### #project-log
| メンバー | メッセージ閲覧 | メッセージ送信 |
|---------|:---:|:---:|
| 全Bot | ✅ | ✅ |

### 3. Bot間通信の仕組み

OpenClawのDiscord統合はデフォルトで他のBotのメッセージを無視します。
Bot間の通信を実現するには、**Discordウェブフック**を使います:

1. 各チャンネルの **設定 → 連携サービス → ウェブフック** で新規ウェブフック作成
2. Alphaが #beta-tasks に指示を書くとき、ウェブフック経由で送信
3. ウェブフック経由のメッセージはBotフィルターをバイパスし、Betaが受信可能

#### ウェブフック作成例
- `#beta-tasks` → ウェブフック名: "Alpha指示" → URLをコピー
- `#gamma-tasks` → ウェブフック名: "Alpha指示" → URLをコピー
- `#review` → ウェブフック名: "成果物" → URLをコピー

## 運用フロー

```
ユーザー: #command-center に「Webアプリを作りたい」と投稿
    ↓
Alpha: 要件を分析し、タスクを分割
    ↓
Alpha → #beta-tasks: 「フロントエンドを作って」
Alpha → #gamma-tasks: 「APIを作って」
    ↓
Beta: #beta-tasks の指示を受けて作業開始
Gamma: #gamma-tasks の指示を受けて作業開始
    ↓
Beta → #review: 成果物を投稿
Gamma → #review: 成果物を投稿
    ↓
Alpha: #review で成果物をレビュー
    ↓ (修正が必要な場合)
Alpha → #beta-tasks: 「ここを修正して」
    ↓ (承認の場合)
Alpha → #command-center: ユーザーに完了報告
```
